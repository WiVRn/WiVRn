# Contributing to WiVRn

WiVRn is developed by volunteers and published under GPL-3 license.

Contributions are welcome, there are few rules that should be followed:

## Setup your development environment

Instructions on how to build the project are in [docs/building.md], for translations please follow [docs/translating.md].

## Acceptable contributions

The project is developed by humans, machine generated code will not be accepted unless it is for trivial changes.

For changes to be accepted, we have to ensure that we can maintain them in the future.
This means that we will be very careful in case of big pull requests. Changes that rely on specification violation or that violate specifications (especially OpenXR and Vulkan) will not be accepted.

## Conventions

The code does not have strict conventions, there is a clang-format file for formatting. Just try to write code that is correct, concise and easy to understand. Details can be discussed in code reviews.
